# Wort · 德语学习

你好！这里是Eve.Austin，本体是一只夜鹭！Deuschland Wort是我用Codex搓的德语单词学习网站，支持词句收藏、间隔复习、随机练习和 AI 辅助学习。本网站适用于“不依赖课本教材、想按照自己的学习进度复习单词”的宝贝们！

## 在线使用

https://eveaustin.github.io/Deuschland/

无需注册 GitHub，直接用浏览器打开即可。

## 功能

- 单词、短语、句子分类与日历管理
- 双向默写、冠词匹配、释义选择
- 随机练习、错题重练与学习总结
- 每日德语一句与文章推荐
- DeepSeek / OpenAI 兼容 API 答疑
- 词句 JSON 导入导出
- 实验性的跨网页划词书签

## 数据与隐私

词句、复习记录和 API 设置保存在当前浏览器，不会自动同步到 GitHub。

API Key 保存在浏览器本地存储中，请仅在可信设备上使用。
AI 请求会将相关问题、答案或所选词句发送给用户配置的服务商，
可能产生 API 费用！

请定期导出词句备份，不要把 API Key 提交到代码仓库。

## 本地使用

下载 index.html 后用浏览器打开即可使用基础功能。
跨网页划词书签需要通过 HTTPS 网站使用，
且可能受到目标网站或浏览器安全策略限制。
