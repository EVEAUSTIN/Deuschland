## 在线使用

https://eveaustin.github.io/Deutschland/

## Windows 桌面应用（64 位）

首次安装：进入 [Releases](https://github.com/EVEAUSTIN/Deutschland/releases/latest)，下载 `Wort-Setup-版本号.exe` 并安装。需要 Windows 10/11 x64。首次构建发布完成后才会出现安装包；源码提交本身不是可执行程序。

桌面应用从安装包加载页面与 Markdown 库，基础学习功能无需联网。AI 由独立的主进程通过 HTTPS 调用，保持系统 TLS 校验，无需关闭浏览器安全设置，也不依赖服务商的浏览器 CORS。文章、词典仍在默认浏览器中打开。桌面应用本身不会注入外部网页；实验性跨网站划词请继续使用网页版书签。

### 从现有网页迁移

1. 在**原来使用的浏览器与网址**打开 Wort，进入词句本，导出 JSON 备份。桌面程序无法读取浏览器中的数据，不要在导出前清除浏览器数据。
2. 安装桌面版，进入词句本，导入该 JSON。支持旧版的词句、分类、未知日期、阶段和作答历史。
3. API Key 不在词句备份里，请在桌面版重新填写。词句备份也不包含临时对话和上一轮总结。
4. 导入会替换桌面版已有词句，不会合并。若已在桌面版录入新词，请先另行导出备份。

### 本地数据与恢复

Windows 的 `%APPDATA%/Wort/wort-store.json` 存储学习数据、设置与上一轮总结；AI 设置页面可以直接打开数据文件夹。每个自然日首次修改前会保留上一份数据库到 `backups/`，保留最近 30 个备份日。数据库采用临时文件和原子替换写入，更新不会把它放入安装目录或覆盖它。

密钥使用 Electron safeStorage（Windows 用户级系统加密）保存，不以明文写入数据库。加密不可用时拒绝明文落盘。加密密钥通常不能移到其他 Windows 账户或电脑解密；跨设备迁移请导出词句 JSON，再重新填写密钥。自动数据库备份可能包含加密后的密钥，勿公开上传数据文件夹。

若数据库损坏，程序不会覆盖原文件。关闭程序，先复制整个数据文件夹保存，再从 `backups` 选择合适文件恢复为 `wort-store.json`；若没有自动备份，先将损坏文件改名保留，再重新启动并导入手动导出的词句 JSON。

### 应用内更新

- 正式安装版启动约 8 秒后检查 GitHub Releases，此后每 4 小时检查；也可以在 AI 页手动检查。
- 发现更新后由用户选择下载。下载通过安装包 SHA-512 校验后，用户确认“保存并重启安装”，才退出并运行安装器；不会自动强制安装。
- 必须发布包含 `.exe`、`.exe.blockmap`、`latest.yml` 的新 Release，客户端才有可安装更新。GitHub 代码改动经下述工作流成功构建和发布后即可升级，不需要用户手动重下安装包。
- GitHub 在部分网络下可能无法访问，检查失败不会影响现有本地学习。更新应用不保证修复网络访问问题。
- 当前社区安装包未配置付费代码签名证书，Windows 可能提示未知发布者。请核对官方仓库和发布来源；项目不会禁用系统安全检查。

### 发布与开发

```sh
npm ci
npm run vendor
npm test
npm run test:browser
npm start
```

浏览器测试先安装 Playwright Chromium：`npx playwright install chromium`；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chromium。`npm run test:desktop` 会实际启动 Electron、验证隔离桥接与本地存储，并重启检查数据持久化。

主分支涉及应用文件的提交会触发 `.github/workflows/desktop-release.yml`：Linux 验证、Windows 验证与 NSIS 安装器构建，并再次启动打包后的 Wort.exe 检查数据持久化和系统密钥加密，之后自动发布 `1.1.<工作流运行序号>` 版本。版本号单调递增；工作流重跑同一版本前应检查是否已有对应 Release。也可通过 GitHub Actions 的 Run workflow 手动发布。仓库必须允许 Actions，发布任务需要内置 GITHUB_TOKEN 的 contents:write 权限，不需要把个人密钥写入源码。

GitHub Pages 仍可直接从 main 根目录部署；Markdown 依赖文件和许可证已随源码提交，无需 CDN。

## 本版修复说明

- AI 查词结果是可编辑草稿：修改德语不会清空中文、例句、类别或日期。查询期间有编辑时，新结果不会自动覆盖草稿，需手动选择应用。
- 新词首次完成到期复习后先间隔 10 分钟；10 分钟仍按真实经过时间计算；1/3/7/14/30 天按设备本地日历零点计算。例如今天 23:58 完成、间隔 1 天，明天 00:00 即到期。旧版长间隔到期时间迁移到对应日期零点，10 分钟任务不截断。应用依赖设备日期、时区和时间正确。
- Markdown 使用随仓库打包的 marked + DOMPurify：GFM 表格、嵌套列表、粗体、标题、引用、代码及安全链接。剔除脚本、事件属性、外部图片等不需要的 HTML，表格在手机上横向滚动。模型若把整段回答包在 markdown 代码围栏内，会先解包再排版；真正代码块保留原样。

第三方格式库许可证见 `vendor/`。项目自身采用根目录 MIT LICENSE。
